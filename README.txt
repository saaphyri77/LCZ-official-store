LuxeCustomzBySai — Official Store Package

READY:
- Exact LCZ storefront + collection reference image
- Six core set prices
- Color and size selections are sent to checkout
- Secure Stripe Checkout endpoint
- Shipping address + phone collected at checkout
- Success and cancel pages
- Mobile cart no longer covers product controls

TO GO LIVE:
1. Upload this folder to a Node.js hosting provider.
2. In the host's Environment Variables, add STRIPE_SECRET_KEY using the secret key from your Stripe Dashboard. NEVER put it in index.html or send it in chat.
3. Optional: set PUBLIC_URL to your final https:// domain.
4. Deploy.
5. Make one small test purchase in Stripe test mode before switching to live mode.

Prices are validated on the SERVER, not trusted from the browser.
Current shipping: $8.99 flat U.S. standard shipping for orders under $100. FREE standard shipping on orders $100 and up. Stripe collects the U.S. shipping address during checkout.
